SIMECID – Sistema de Citas Médicas

SIMECID es una plataforma web diseñada para gestionar la reserva y consulta de citas médicas. Permite a los pacientes visualizar disponibilidad, gestionar sus citas y mantener un historial básico.

Tecnologías: C# (backend), HTML, CSS, JavaScript (frontend).

Incluye módulos para administración de pacientes, agenda de médicos y validación de datos de entrada.
