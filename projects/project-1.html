SIMECID — Plataforma de Citas Médicas

Sistema web para la gestión de citas médicas, permitiendo a los pacientes consultar disponibilidad, reservar citas y visualizar historial. Incluye backend en C# con validaciones, control de usuarios y manejo de solicitudes, además de una interfaz web ligera desarrollada con HTML, CSS y JavaScript.

  • Tech: C# · HTML · CSS · JavaScript
  • Frontend: HTML/CSS/JS
  • Backend: C#
